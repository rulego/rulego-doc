<Badge text="rulego-components-discovery"/> 提供 nacos 微服务生态接入能力：**服务发现调用**、**配置读取**、**配置写入**、**配置变更监听**。

> 需要额外引入扩展库：[rulego-components-discovery](https://github.com/rulego/rulego-components-discovery)

## 定位

作为「单例成员」接入微服务集群——rulego 保持单例，通过 nacos 完成服务发现、配置读取、写入与监听，不引入多副本选主等分布式问题。多实例 HA/选主是独立的运行时议题，不在本库范围。

## 组件清单

| 组件 | 说明 |
|------|------|
| [x/nacosServiceCall](/pages/x-nacos-service-call/) | 通过 nacos 服务发现定位健康实例并调用集群微服务 |
| [x/nacosConfigGet](/pages/x-nacos-config-get/) | 从 nacos 读取配置内容 |
| [x/nacosConfigSet](/pages/x-nacos-config-set/) | 全量写入（发布）nacos 配置 |
| [endpoint/nacos](/pages/endpoint-nacos/) | 监听 nacos 配置变更，变更自动触发规则链 |

## 公共连接配置

所有组件共享 `ConnConfig`（匿名嵌入，JSON 字段平铺到组件 configuration）：

| 字段 | 类型 | 说明 | 默认值 |
|---|---|---|---|
| server | string | nacos 地址列表，逗号分隔，如 `127.0.0.1:8848` | 127.0.0.1:8848 |
| namespace | string | 命名空间 ID | 空（public） |
| timeout | int | 请求超时（秒）；服务调用同时约束 HTTP 调用超时 | 5 |
| auth | object | 认证：开源鉴权用 `username`/`password`，阿里云用 `accessKey`/`secretKey` | 无 |
| tls | object | TLS：`certFile`/`certKeyFile`/`caFile`/`insecureSkipVerify` | 无 |

> 同一 `server` 的多个组件自动复用 nacos 客户端连接（base.SharedNode）；也可用 `ref://ownerId` 显式复用画布上已有节点的连接。

## 引入方式

```go
import (
    _ "github.com/rulego/rulego-components-discovery/external/nacos"
    _ "github.com/rulego/rulego-components-discovery/endpoint/nacos"
)
```

无特殊构建标签，blank import 即注册全部组件。
