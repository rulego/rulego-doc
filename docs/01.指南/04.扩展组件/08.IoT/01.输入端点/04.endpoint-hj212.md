***HJ212 接收端点*** <Badge text="v0.37.0+"/> 监听 TCP 端口，被动接收污染源在线监控设备按 HJ 212-2017 标准主动上报的数据帧，解析污染物因子为统一 `iot_points.Data` 流入规则链。仅做被动采集，不主动应答设备（Flag bit0 应答由下游规则自行处理）。

::: tip
1. 该组件是扩展组件，需要引入额外的扩展库：[rulego-components-iot](https://github.com/rulego/rulego-components-iot)
:::

## Type

endpoint/hj212

## 配置

| 字段 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| server | string | 监听地址（含端口），例如 `0.0.0.0:8005` | `0.0.0.0:8005` |

::: tip 路由
该端点为被动接收、单路由无路径区分，路由配置默认隐藏（保存时自动注入 `from.path='*'` 默认路由），无需手动配置。
:::

## 接收消息格式

每收到一帧，组件把解析出的污染物因子点位列表转为 `RuleMsg` 流入规则链，`msg.type` 为 `HJ212`，`dataType` 为 `JSON`，`msg.Data` 为点位数组 JSON 字符串：

```json
[
  { "name": "w01018-Rtd", "value": 7.5, "timestamp": 0 }
]
```

| 字段 | 类型 | 说明 |
|------|------|------|
| name | string | 污染物因子编码（如 `w01018-Rtd` 实时值） |
| value | any | 因子值 |
| timestamp | number | 纳秒时间戳（0=当前时间） |

## 元数据(metadata)

每收到一帧，组件还会把帧头字段写入 `msg.Metadata`，方便下游节点用 `${metadata.xx}` 取值：

| key | 说明 |
|-----|------|
| from | 发送设备地址（`host:port`） |
| mn | 设备唯一标识 MN |
| st | 系统编码 ST（子系统类型） |
| cn | 命令编码 CN（如 `2011` 实时数据） |
| dataTime | 数据时间（`YYYY-MM-DD HH:mm:ss`，帧未带时省略） |

## 特性

- **被动监听**：不主动请求设备，仅接收设备按 HJ 212-2017 主动上报的数据帧。
- **统一契约**：解析结果为 `iot_points.Data`，可直接由 [`x/tsdbWrite`](/pages/x-tsdb-write/)（配置 `measurement` 后自动透视为时序点）落盘。
- **应答可选**：帧 Flag bit0=1 时自动回写 ACK 确认帧；否则不应答。
- **优雅停机**：支持 graceful shutdown，停机时等待处理中的连接完成。
