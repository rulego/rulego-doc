`endpoint/modbusServer`组件：<Badge text="v0.37.0+"/>Modbus TCP 从站端点，监听 TCP 端口接受主站连接，主站写 Coil/Holding Register 时触发消息流入规则链。

> 需要额外引入扩展库： [rulego-components-iot](https://github.com/rulego/rulego-components-iot)

## 配置

| 字段 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| listen | string | 监听地址，格式 tcp://host:port | `tcp://:502` |
| unitId | int | 从站地址（0=接受所有） | `0` |
| maxClients | uint | 最大并发连接数 | `10` |
| coils | uint | Coil 区大小（位） | `2000` |
| registers | uint | 寄存器区大小（字） | `2000` |

## 工作模式

1. **内存寄存器表**：维护 4 区内存表（Coils/DI/HR/IR），主站读时返回表值
2. **写触发规则链**：主站写 Holding Register 或 Coil 时，把写入数据转为消息流入规则链
3. **外部回写**：规则链处理后可通过 SetRegisters/SetCoils 更新寄存器表，供主站读取

## 写触发消息格式

```json
{
  "type": "holding_register",
  "unitId": 1,
  "addr": 100,
  "quantity": 2,
  "values": [1234, 5678],
  "clientAddr": "192.168.1.10:54321"
}
```

Metadata 注入：`modbusType`（coil/holding_register）、`clientAddr`。

## 应用场景

- **SCADA 桥接**：上位机写寄存器 → 触发规则链联动
- **虚拟设备**：规则链更新寄存器值 → 主站轮询读取
- **写触发流**：PLC 写入 → 触发告警/联动/数据记录
