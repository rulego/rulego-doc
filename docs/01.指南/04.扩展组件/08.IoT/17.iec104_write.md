`x/iec104Write`组件：IEC 104 遥控/遥调，支持单命令、双命令、标度化设点、短浮点设点。

> 需要额外引入扩展库： [rulego-components-iot](https://github.com/rulego/rulego-components-iot)

## 配置

同 `x/iec104Read`（server/commonAddr/timeout/points）。

## 命令类型

| Type | 说明 | Value 格式 |
|------|------|-----------|
| C_SC_NA_1 | 单命令（遥控） | true/false 或 1/0 |
| C_DC_NA_1 | 双命令（遥控） | 1(合)/2(分) |
| C_SE_NB_1 | 标度化设点（遥调） | 整数（int16 范围） |
| C_SE_NC_1 | 短浮点设点（遥调） | 浮点数 |

## 输入/输出

- **输入**：msg.Data 带点位列表 `[{"name","addr","type","value"}]`
- **输出**：成功走 Success 链，失败走 Failure 链

## 示例

```json
[
  {"name": "合闸", "addr": "100", "type": "C_SC_NA_1", "value": "true"},
  {"name": "设定功率", "addr": "700", "type": "C_SE_NC_1", "value": "50.5"}
]
```
