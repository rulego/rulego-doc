`x/finsRead` / `x/finsWrite`组件：欧姆龙 FINS 协议（UDP/TCP），读写 CS/CJ/CP/NSJ 系列 PLC 内存区。

> 需要额外引入扩展库： [rulego-components-iot](https://github.com/rulego/rulego-components-iot)

## 配置

| 字段 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| server | string | PLC 地址 host:port | `127.0.0.1:9600` |
| transport | string | 传输方式：udp/tcp | `udp` |
| timeout | int | 超时（秒） | `5` |
| points | array | 点位表 | — |

## 地址格式

| 区 | 字地址 | 位地址 | 示例 |
|---|---|---|---|
| DM | DM100 | DM100.3 | 数据存储区 |
| CIO | CIO100 | CIO10.0 | CPU I/O 区 |
| WR | WR200 | WR200.5 | 内部辅助区 |
| HR | HR50 | HR50.2 | 保持继电器 |
| AR | AR10 | AR10.7 | 特殊辅助 |

## 支持的数据类型

BOOL、INT16、UINT16、INT32、UINT32、FLOAT32（支持点位级 Endian：ABCD/CDAB/BADC/DCBA）

## 输入/输出

- **读输出**：`[{"name","value","timestamp"}]`
- **写输入**：`[{"name","addr","type","value"}]`
