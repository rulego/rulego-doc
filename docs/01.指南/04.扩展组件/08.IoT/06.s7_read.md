`x/s7Read` 组件：<Badge text="v0.35.0+"/> 用于批量读取西门子 S7 系列 PLC（S7-200SMART/300/400/1200/1500）的点位数据，结果写回 `msg.Data`，经 `Success` 链转出。

> 需要额外引入扩展库：[rulego-components-iot](https://github.com/rulego/rulego-components-iot)

## 配置

| 字段 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| server | string | PLC 地址，格式 `host:port`，ISO-on-TCP 默认端口 102 | `127.0.0.1:102` |
| rack | int | 机架号 | `0` |
| slot | int | CPU 槽位：S7-1200/1500/200SMART=1，S7-300/400=2 | `1` |
| timeout | int | 请求超时时间，单位为秒 | `5` |
| points | []object | 默认点位表；`msg.Data` 携带合法点位时优先使用 `msg.Data` | `[]` |

### 点位(points)字段

| 字段 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| name | string | 点位名称（输出带上，便于下游取值） | 无 |
| area | string | 区域，可选值：`DB`(数据块)/`M`(标志区)/`I`(输入)/`Q`(输出) | 无 |
| dbNumber | string | 数据块号，仅 `area=DB` 时有效；支持 `${msg.xx}` | 无 |
| address | string | 字节偏移（纯数字字符串）；支持 `${msg.xx}` | 无 |
| type | string | 数据类型，可选值见下表 | 无 |
| bitOffset | string | 位偏移，仅 `type=BOOL` 有效，范围 0-7；支持 `${msg.xx}` | `0` |
| count | string | 读取数量，默认 1；`STRING` 类型忽略此字段；支持 `${msg.xx}` | `1` |

## 点位(Point)字段说明

**区域(area)可选值：**

| 值 | 区域 | 说明 |
|----|------|------|
| `DB` | 数据块 (Data Block) | 读取 DB 区，需指定 `dbNumber` |
| `M` | 标志区 (Markers) | 内部标志位存储区 |
| `I` | 输入 (Inputs) | 过程映像输入区 |
| `Q` | 输出 (Outputs) | 过程映像输出区 |

**address 字段：** 配置中填写**字节偏移**（纯数字字符串，如 `"0"`、`"10"`，支持 `${msg.xx}`）。读节点输出时由组件按 `DB{dbNumber}.{字节偏移}[.{位偏移}]`（DB 区）或 `{区}{字节偏移}[.{位偏移}]`（M/I/Q 区）的格式拼装为可读地址串，如 `DB1.0`、`DB1.0.0`、`M10`、`M10.5`。

**数据类型(type)可选值：**

| 类型 | 字节数 | Go 输出类型 | 说明 |
|------|--------|-------------|------|
| `BOOL` | 1 | bool | 布尔量，需配合 `bitOffset`(0-7) |
| `BYTE` | 1 | byte | 字节 |
| `INT` | 2 | int16 | 有符号 16 位整数（大端） |
| `WORD` | 2 | uint16 | 无符号 16 位整数（大端） |
| `DINT` | 4 | int32 | 有符号 32 位整数（大端） |
| `DWORD` | 4 | uint32 | 无符号 32 位整数（大端） |
| `REAL` | 4 | float32 | 32 位浮点数（大端） |
| `LREAL` | 8 | float64 | 64 位浮点数（大端） |
| `STRING` | 256 | string | S7 字符串（首字节为最大长度，次字节为实际长度） |

## 输出

读取结果重新赋值到 `msg.Data`，通过 `Success` 链传给下一个节点，格式为数组：

| 字段 | 类型 | 说明 |
|------|------|------|
| name | string | 点位名称 |
| address | string | 可读地址串，如 `DB1.0`、`M10.5` |
| value | any | 读取值，类型由 `type` 决定 |
| type | string | 数据类型（大写） |
| quality | string | 读取质量：`good` 成功 / `bad` 失败（单个点位失败不影响其他点位） |
| timestamp | string | 读取时间（RFC3339） |

示例数据：
```json
[
  {"name":"温度","address":"DB1.0","value":25.6,"type":"REAL","quality":"good","timestamp":"2026-07-23T10:00:00Z"},
  {"name":"运行","address":"M10.5","value":true,"type":"BOOL","quality":"good","timestamp":"2026-07-23T10:00:00Z"}
]
```

## 特性

- **定时采集**：搭配 `endpoint/schedule` 定时端点前置触发，点位在下方 `points` 配置；按需读取可由上游节点在 `msg.Data` 注入点位。
- **模板变量**：`dbNumber`、`address`、`bitOffset`、`count` 等点位字段均支持 `${msg.xx}` / `${metadata.xx}` 模板变量。
- **动态点位优先**：`msg.Data` 携带合法点位 JSON 列表时优先使用，否则回退到配置的 `points`。
- **同链连接池**：链内可通过 `ref://节点ID` 借用复用其他 S7 节点已建立的 TCP 连接，避免重复建连。
- **失败重连重试**：连接级失败（全部点位失败）自动重连并重试，最多 3 次（`maxRetries=3`）；单个点位失败仅标记 `quality=bad`，不中断整体流程。

## Relation Type

- ***Success:*** 执行成功，把消息发送到 `Success` 链。
- ***Failure:*** 执行失败，把消息发送到 `Failure` 链。
