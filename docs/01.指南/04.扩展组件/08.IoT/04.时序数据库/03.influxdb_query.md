`x/influxdbQuery`组件：<Badge text="v0.37.0+"/>执行 InfluxDB Flux 查询并返回结果。适合做时序回读、对账和查询分析。

> 需要额外引入扩展库： [rulego-components-iot](https://github.com/rulego/rulego-components-iot)

## 配置

| 字段 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| url | string | 服务地址，格式 `http://host:port`，例如 `http://localhost:8086`。支持 `ref://` 复用同链连接 | 必填 |
| bucket | string | 存储桶名，支持 `${msg.xx}`/`${metadata.xx}` 模板 | 必填 |
| org | string | 组织名，支持 `${msg.xx}`/`${metadata.xx}` 模板 | 必填 |
| token | string | InfluxDB 访问令牌 | 必填 |
| query | string | Flux 查询语句，支持 `${msg.xx}`/`${metadata.xx}` 模板 | 必填 |
