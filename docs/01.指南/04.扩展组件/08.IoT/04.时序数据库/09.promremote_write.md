`x/promremoteWrite`组件：<Badge text="v0.37.0+"/>按 Prometheus Remote Write 协议写入 Prometheus、VictoriaMetrics、Mimir 等后端。仅数值字段会被写入，metric 名会按 measurement/field 组合生成。

> 需要额外引入扩展库： [rulego-components-iot](https://github.com/rulego/rulego-components-iot)

## 配置

| 字段 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| url | string | Remote Write HTTP 地址，例如 `http://localhost:8428/api/v1/write`。支持 `ref://` 复用同链连接 | 必填 |
| measurement | string | 测点表名（可选）。配置后可直接把采集点数组透视为 SeriesPoint；留空则输入必须已经是 SeriesPoint | 空 |
| tags | array | 落盘索引维度（作为 metric label），见下表 | 空 |
| fields | array | 落盘字段映射，见下表；留空=全量展开所有采集点 | 空 |

### tags

每一项为一个键值对：

| key | value |
|-----|-------|
| label 名 | label 值，支持 `${msg.xx}` 模板 |

### fields

每一项为一个字段映射：

| key | source |
|-----|--------|
| metric 字段名 | 采集点 name；留空=全量展开所有采集点 |

## 输入格式（msg.Data）

输入为 SeriesPoint JSON 数组（或单对象）。配置 `measurement` 后可接收 `iot_points.Data` 采集点数组自动透视。SeriesPoint 结构同 [`x/tsdbWrite`](/pages/x-tsdb-write/)。

> 仅数值型 field 会被写入；非数值字段将被忽略。metric 名按 `{measurement}_{field}` 组合生成，tags 作为 label。
