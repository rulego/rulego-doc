`x/influxdbWrite`组件：<Badge text="v0.37.0+"/>写入 InfluxDB 2.x 时序数据库，支持 JSON SeriesPoint 和 line protocol。适合与 [`x/tsdbWrite`](/pages/x-tsdb-write/) 统一抽象配套使用。

> 需要额外引入扩展库： [rulego-components-iot](https://github.com/rulego/rulego-components-iot)

## 配置

| 字段 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| url | string | 服务地址，格式 `http://host:port`，例如 `http://localhost:8086`。支持 `ref://` 复用同链连接 | 必填 |
| bucket | string | 存储桶名，支持 `${msg.xx}`/`${metadata.xx}` 模板 | 必填 |
| org | string | 组织名，支持 `${msg.xx}`/`${metadata.xx}` 模板 | 必填 |
| token | string | InfluxDB 访问令牌 | 必填 |
| measurement | string | 测点表名（可选）。配置后可直接把采集点数组透视为 SeriesPoint，或把扁平 map/map 数组逐行转换为 SeriesPoint；留空则输入必须已经是 SeriesPoint | 空 |
| tags | array | 落盘索引维度，见下表 | 空 |
| fields | array | 落盘字段映射，见下表；留空=全量展开（采集点）或整行 map 作为 fields | 空 |

### tags

每一项为一个键值对：

| key | value |
|-----|-------|
| 索引维度名 | 索引值，支持 `${msg.xx}` 模板 |

### fields

每一项为一个字段映射：

| key | source |
|-----|--------|
| 落盘字段名 | 采集点 name 或 map key；留空=全量展开 |

## 输入格式（msg.Data）

输入为 SeriesPoint JSON 数组（或单对象），也可为 line protocol 文本。配置 `measurement` 后可接收 `iot_points.Data` 采集点数组自动透视，或扁平 map/map 数组逐行转换。SeriesPoint 结构同 [`x/tsdbWrite`](/pages/x-tsdb-write/)。
