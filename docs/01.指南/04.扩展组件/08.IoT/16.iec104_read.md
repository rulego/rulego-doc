`x/iec104Read`组件：IEC 60870-5-104 电力远动主站，总召唤批量采集子站遥信/遥测/遥脉。

> 需要额外引入扩展库： [rulego-components-iot](https://github.com/rulego/rulego-components-iot)

## 配置

| 字段 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| server | string | 子站地址 host:port，默认端口 2404 | `127.0.0.1:2404` |
| commonAddr | int | ASDU 公共地址（站址） | `1` |
| timeout | int | 总召唤等待超时（秒） | `5` |
| points | array | 默认点位表（addr=IOA） | 见下方 |

### 点位表字段

| 字段 | 说明 | 示例 |
|------|------|------|
| name | 点位名称 | 断路器1 |
| addr | 信息体地址(IOA) | 100、16385 |
| type | 类型标识（可选，仅说明） | M_SP_NA_1、M_ME_NC_1 |

## 采集模型

读时发起**总召唤(GI)**，子站上送全数据后按 IOA 取值。支持 9 种 ASDU 类型：单点/双点遥信、标度化/短浮点遥测、累积量等。

## 输入/输出

- **输入**（可选）：msg.Data 带点位列表 JSON 则优先使用（动态采集）
- **输出**：`[{"name","value","timestamp","error"}]`

## 示例

```json
{
  "server": "192.168.1.10:2404",
  "commonAddr": 1,
  "timeout": 5,
  "points": [
    {"name": "断路器1", "addr": "1", "type": "M_SP_NA_1"},
    {"name": "A相电压", "addr": "16385", "type": "M_ME_NC_1"}
  ]
}
```
