`x/mcRead` / `x/mcWrite`组件：三菱 MC 协议（SLMP/3E 帧），读写 Q/L/R/FX5U 系列 PLC 软元件。

> 需要额外引入扩展库： [rulego-components-iot](https://github.com/rulego/rulego-components-iot)

## 配置

| 字段 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| server | string | PLC 地址 host:port | `127.0.0.1:6000` |
| timeout | int | 超时（秒） | `5` |
| points | array | 点位表 | — |

## 地址格式（软元件）

| 软元件 | 字访问 | 位访问 | 说明 |
|--------|--------|--------|------|
| D | D100 | — | 数据寄存器 |
| W | W200 | — | 链接寄存器 |
| ZR | ZR300 | — | 文件寄存器 |
| M | — | M10 | 内部继电器 |
| SM | — | SM400 | 特殊继电器 |
| X | — | X1A0 | 输入（十六进制） |
| Y | — | Y30 | 输出（十六进制） |
| C | C10 | C10 | 计数器 |
| L | — | L10 | 锁存继电器 |

## 支持的数据类型

BOOL、INT16、UINT16、INT32、UINT32、FLOAT32、FLOAT64（支持 Endian）

## 输入/输出

- **读输出**：`[{"name","value","timestamp"}]`
- **写输入**：`[{"name","addr","type","value"}]`
