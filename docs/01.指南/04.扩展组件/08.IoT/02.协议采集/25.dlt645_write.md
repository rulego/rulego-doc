`x/dlt645Write`组件：<Badge text="v0.37.0+"/> 通过 DL/T 645-2007 协议写入电表数据项，适用于校时、参数下发等场景，成功走 `Success` 链、失败走 `Failure` 链。

> 需要额外引入扩展库： [rulego-components-iot](https://github.com/rulego/rulego-components-iot)

## 配置

连接配置与 [x/dlt645Read](/pages/x-dlt645-read/) 相同（server/addr/timeout/points）。写入点位由 `msg.Data` 传入。

## 输入/输出

- **输入**：`msg.Data` 带点位列表 `[{"name","addr","type","value"}]`
- **输出**：成功走 `Success` 链，失败走 `Failure` 链

## 示例

```json
{
  "id": "dlt645_write",
  "type": "x/dlt645Write",
  "configuration": {
    "server": "192.168.1.40:8899",
    "addr": "000000000001"
  }
}
```

`msg.Data` 传入写入点位：

```json
[
  {"name": "校时", "addr": "0F-01-00-00", "type": "BCD", "value": "240726120000"}
]
```
