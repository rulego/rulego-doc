`x/finsWrite`组件：<Badge text="v0.37.0+"/> 通过欧姆龙 FINS 协议（UDP/TCP）批量写入 PLC 内存区，成功走 `Success` 链、失败走 `Failure` 链。

> 需要额外引入扩展库： [rulego-components-iot](https://github.com/rulego/rulego-components-iot)

## 配置

连接配置与 [x/finsRead](/pages/x-fins/) 相同（server/transport/network/dstNode/srcNode/unit/timeout/points）。写入点位由 `msg.Data` 传入。

## 页面导航

- 读取：[x/finsRead](/pages/x-fins/)
- 统一采集入口：[x/iotRead](/pages/x-iot-read/)（driver=fins）
- 统一写入入口：[x/iotWrite](/pages/x-iot-write/)（driver=fins）
- 转时序点：[x/iotToSeries](/pages/x-iot-to-series/) -> [x/tsdbWrite](/pages/x-tsdb-write/)

## 输入/输出

- **输入**：`msg.Data` 带点位列表 `[{"name","addr","type","value"}]`
- **输出**：成功走 `Success` 链，失败走 `Failure` 链

## 示例

```json
{
  "id": "fins_write",
  "type": "x/finsWrite",
  "configuration": {
    "server": "192.168.1.20:9600",
    "transport": "udp"
  }
}
```

`msg.Data` 传入写入点位：

```json
[
  {"name": "设定值", "addr": "DM200", "type": "UINT16", "value": "1234"},
  {"name": "启动", "addr": "CIO20.0", "type": "BOOL", "value": "true"}
]
```
