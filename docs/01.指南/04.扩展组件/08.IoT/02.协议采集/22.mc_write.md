`x/mcWrite`组件：<Badge text="v0.37.0+"/> 通过三菱 MC 协议（3E 帧/二进制，SLMP）批量写入 PLC 软元件，成功走 `Success` 链、失败走 `Failure` 链。

> 需要额外引入扩展库： [rulego-components-iot](https://github.com/rulego/rulego-components-iot)

## 配置

连接配置与 [x/mcRead](/pages/x-mc-read/) 相同（server/timeout/points）。写入点位由 `msg.Data` 传入。

## 输入/输出

- **输入**：`msg.Data` 带点位列表 `[{"name","addr","type","value"}]`
- **输出**：成功走 `Success` 链，失败走 `Failure` 链

## 示例

```json
{
  "id": "mc_write",
  "type": "x/mcWrite",
  "configuration": {
    "server": "192.168.1.30:6000"
  }
}
```

`msg.Data` 传入写入点位：

```json
[
  {"name": "设定转速", "addr": "D200", "type": "UINT16", "value": "1500"},
  {"name": "启动", "addr": "M10", "type": "BOOL", "value": "true"}
]
```
