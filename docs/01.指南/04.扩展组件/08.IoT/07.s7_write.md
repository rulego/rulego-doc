`x/s7Write` 组件：<Badge text="v0.35.0+"/> 用于把点位值列表批量写入西门子 S7 系列 PLC（S7-200SMART/300/400/1200/1500），成功经 `Success` 链转出。

> 需要额外引入扩展库：[rulego-components-iot](https://github.com/rulego/rulego-components-iot)

## 配置

| 字段 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| server | string | PLC 地址，格式 `host:port`，ISO-on-TCP 默认端口 102 | `127.0.0.1:102` |
| rack | int | 机架号 | `0` |
| slot | int | CPU 槽位：S7-1200/1500/200SMART=1，S7-300/400=2 | `1` |
| timeout | int | 请求超时时间，单位为秒 | `5` |
| points | []object | 默认点位表；`msg.Data` 携带合法点位时优先使用 `msg.Data` | `[]` |

### 点位(points)字段

| 字段 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| name | string | 点位名称 | 无 |
| area | string | 区域，可选值：`DB`(数据块)/`M`(标志区)/`I`(输入)/`Q`(输出) | 无 |
| dbNumber | string | 数据块号，仅 `area=DB` 时有效；支持 `${msg.xx}` | 无 |
| address | string | 字节偏移（纯数字字符串）；支持 `${msg.xx}` | 无 |
| type | string | 数据类型，可选值见下表 | 无 |
| bitOffset | string | 位偏移，仅 `type=BOOL` 有效，范围 0-7；支持 `${msg.xx}` | `0` |
| count | string | 数量，默认 1；写入仅写单值，通常不使用；支持 `${msg.xx}` | `1` |
| value | string | 待写入值（字符串形式）；支持 `${msg.xx}` | 无 |

## 点位(Point)字段说明

**区域(area)可选值：**

| 值 | 区域 | 说明 |
|----|------|------|
| `DB` | 数据块 (Data Block) | 写入 DB 区，需指定 `dbNumber` |
| `M` | 标志区 (Markers) | 内部标志位存储区 |
| `I` | 输入 (Inputs) | 过程映像输入区 |
| `Q` | 输出 (Outputs) | 过程映像输出区 |

**address 字段：** 配置中填写**字节偏移**（纯数字字符串，如 `"0"`、`"10"`，支持 `${msg.xx}`）。

**数据类型(type)可选值：**

| 类型 | 字节数 | 值格式说明 |
|------|--------|------------|
| `BOOL` | 1 | 布尔量，`value` 支持 `true`/`false`/`0`/`1`，需配合 `bitOffset`(0-7)；底层按读-改-写实现 |
| `BYTE` | 1 | 无符号字节 |
| `INT` | 2 | 有符号 16 位整数 |
| `WORD` | 2 | 无符号 16 位整数 |
| `DINT` | 4 | 有符号 32 位整数 |
| `DWORD` | 4 | 无符号 32 位整数 |
| `REAL` | 4 | 32 位浮点数 |
| `LREAL` | 8 | 64 位浮点数 |
| `STRING` | 256 | S7 字符串，内容超过 254 字节将截断 |

## 输入

写入点位从 `msg.Data` 读取（JSON 数组）；若 `msg.Data` 为空则回退到配置的 `points`。每个点位对象字段如下：

| 字段 | 类型 | 说明 |
|------|------|------|
| area | string | 区域：`DB`/`M`/`I`/`Q` |
| dbNumber | string/int | 数据块号，仅 `area=DB` 时有效 |
| address | string/int | 字节偏移 |
| type | string | 数据类型 |
| bitOffset | string/int | 位偏移，仅 `type=BOOL` |
| count | string/int | 数量，默认 1 |
| value | string | 待写入值，支持 `${msg.xx}` |

示例 `msg.Data`：
```json
[
  {"area":"DB","dbNumber":"1","address":"0","type":"REAL","value":"25.6"},
  {"area":"M","address":"10","type":"BOOL","bitOffset":"0","value":"true"}
]
```

## 特性

- **定时写入**：搭配 `endpoint/schedule` 定时端点前置触发；按需写入可由上游节点在 `msg.Data` 注入点位列表。
- **模板变量**：`dbNumber`、`address`、`bitOffset`、`count`、`value` 等点位字段均支持 `${msg.xx}` / `${metadata.xx}` 模板变量。
- **动态点位优先**：`msg.Data` 携带合法点位 JSON 列表时优先使用，否则回退到配置的 `points`。
- **同链连接池**：链内可通过 `ref://节点ID` 借用复用其他 S7 节点已建立的 TCP 连接，避免重复建连。
- **失败重连重试**：写入失败自动重连并重试，最多 3 次（`maxRetries=3`）；任一点位失败即整体失败并走 `Failure` 链。

## Relation Type

- ***Success:*** 执行成功，把消息发送到 `Success` 链。
- ***Failure:*** 执行失败，把消息发送到 `Failure` 链。

```json
    "firstNodeIndex": 0,
    "nodes": [
      {
        "type": "x/s7Write",

        "configuration": {
          "server": "192.168.1.100:102",
          "rack": 0,
          "slot": 1,
          "timeout": 5,

            {"name":"启动","area":"M","address":"10","type":"BOOL","bitOffset":"0","value":"true"}
          ]
        }
      }
    ],
    "connections": []
  }
}
```
