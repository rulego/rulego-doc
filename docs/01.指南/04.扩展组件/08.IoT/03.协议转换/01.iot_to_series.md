`x/iotToSeries`组件：<Badge text="v0.37.0+"/> 把 `msg.Data` 中的 map 对象或 map 数组转换为 `[]tsdb.SeriesPoint`，用于衔接采集聚合结果与 [x/tsdbWrite](/pages/x-tsdb-write/)。

> 需要额外引入扩展库： [rulego-components-iot](https://github.com/rulego/rulego-components-iot)

## 配置

| 字段 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| measurement | string | 测点表名，支持 `${msg.xx}` / `${metadata.xx}` 模板 | `iot_data` |
| tags | object | tag 键值映射，value 支持模板 | 空 |
| fields | object | 字段映射：`{字段名: 来源键}`；留空时直接使用整行数据 | 空 |
| timestampField | string | 行内时间戳字段名（Unix 纳秒）；留空时使用当前时间 | 空 |

## 输入格式

支持以下两种输入：

- **单个对象**

```json
{"temperature": 25.3, "humidity": 60, "ts": 1721900000000000000}
```

- **对象数组**

```json
[
  {"device": "d1", "temperature": 25.3, "ts": 1721900000000000000},
  {"device": "d2", "temperature": 26.1, "ts": 1721900001000000000}
]
```

## 输出格式

输出到 `msg.Data` 的数据为 `[]tsdb.SeriesPoint`：

```json
[
  {
    "measurement": "power_meter",
    "tags": {"deviceId": "d1"},
    "fields": {"temp": 25.3},
    "timestamp": 1721900000000000000
  }
]
```

## 字段映射规则

- `measurement`：每一行共用同一个测点名，支持模板渲染
- `tags`：按配置模板生成字符串标签
- `fields`：留空时使用整行 map；不为空时仅提取映射中声明的字段
- `timestampField`：若指定字段不存在或格式错误，则回退为当前时间

## 示例

```json
{
  "id": "series",
  "type": "x/iotToSeries",
  "configuration": {
    "measurement": "power_meter",
    "tags": {
      "deviceId": "${metadata.deviceId}",
      "site": "${metadata.site}"
    },
    "fields": {
      "temp": "temperature",
      "hum": "humidity"
    },
    "timestampField": "ts"
  }
}
```

输入 `msg.Data`：

```json
{"temperature": 25.3, "humidity": 60, "ts": 1721900000000000000}
```

## 典型链路

```text
x/iotRead -> x/streamAggregator(透视) -> x/iotToSeries -> x/tsdbWrite
```
