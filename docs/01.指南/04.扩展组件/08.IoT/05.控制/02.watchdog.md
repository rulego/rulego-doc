`x/control/watchdog` 组件：看门狗，监测消息流连续性。每条到达的消息透传至下游并重新武装计时；超时未收到消息则把预设的故障安全 JSON（如关阀、停电机）下发下游。协议无关，常串接在 `x/iotWrite` 之前做上位机失联保护。

> 需要额外引入扩展库：[rulego-components-iot](https://github.com/rulego/rulego-components-iot)

## 配置

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| timeout | string | 是 | 看门狗超时时长，如 `10s`、`500ms`；支持 `${metadata.xx}` 模板 |
| failsafe | object | 否 | 超时下发下游的 JSON 载荷，如 `{"valve":0,"motor":0}`；写入 `msg.Data` 经 `Success` 链转出 |

## 行为

- 收到消息：原始消息透传至下游，并重新武装（复位计时）。
- 达 `timeout` 未收到消息：经 `Success` 链下发 `failsafe` JSON。

## Relation Type

- ***Success:*** 消息透传，或下发故障安全载荷。
- ***Failure:*** 执行失败，把消息发送到 `Failure` 链。

## 示例

```json
{
  "ruleChain": {
    "id": "watchdog_demo",
    "name": "看门狗故障安全示例",
    "root": true,
    "debugMode": false
  },
  "metadata": {
    "firstNodeIndex": 0,
    "nodes": [
      {
        "type": "x/control/watchdog",
        "name": "上位机失联保护",
        "debugMode": false,
        "configuration": {
          "timeout": "10s",
          "failsafe": {"valve": 0, "motor": 0}
        }
      }
    ],
    "connections": []
  }
}
```
