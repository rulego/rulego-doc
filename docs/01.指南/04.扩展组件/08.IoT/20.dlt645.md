`x/dlt645Read` / `x/dlt645Write`组件：DL/T 645-2007 电力多功能电能表通信协议，TCP 透传方式读写数据项。

> 需要额外引入扩展库： [rulego-components-iot](https://github.com/rulego/rulego-components-iot)

## 配置

| 字段 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| server | string | 电表 TCP 地址（串口服务器透传端口） | `127.0.0.1:8899` |
| addr | string | 12 位 BCD 表地址 | `000000000001` |
| timeout | int | 超时（秒） | `5` |
| points | array | 点位表（addr=DI 数据标识） | — |

## 地址格式（DI 数据标识）

格式：`XX-XX-XX-XX`（4 字节，常用示例）

| DI | 说明 |
|----|------|
| 00-01-00-00 | 正向有功总电能 |
| 02-01-01-00 | A 相电压 |
| 02-02-01-00 | A 相电流 |
| 02-03-00-00 | 瞬时总有功功率 |
| 04-00-01-01 | 表号 |

## 数据类型

- **BCD**（默认）：标准 BCD 编码，自动按 DI 确定小数位
- **BCD_SIGNED**：带符号 BCD
- **INT16/UINT16/INT32/UINT32/INT64/UINT64**：二进制整数
- **BOOL/STRING**：特殊类型

## 输入/输出

- **读输出**：`[{"name","value","timestamp"}]`（自动按 DI 标准信息确定小数位）
- **写输入**：`[{"name","addr","type","value"}]`
