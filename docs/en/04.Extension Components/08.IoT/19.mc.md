`x/mcRead` / `x/mcWrite`: Mitsubishi MC protocol (SLMP/3E frame), reads/writes Q/L/R/FX5U series PLC devices.

> Requires: [rulego-components-iot](https://github.com/rulego/rulego-components-iot)

## Configuration

| Field | Type | Description | Default |
|-------|------|-------------|---------|
| server | string | PLC host:port | `127.0.0.1:6000` |
| timeout | int | Timeout (seconds) | `5` |
| points | array | Point table | — |

## Address Format (Devices)

| Device | Word | Bit | Description |
|--------|------|-----|-------------|
| D | D100 | — | Data register |
| W | W200 | — | Link register |
| ZR | ZR300 | — | File register |
| M | — | M10 | Internal relay |
| SM | — | SM400 | Special relay |
| X | — | X1A0 | Input (hex) |
| Y | — | Y30 | Output (hex) |

## Data Types

BOOL, INT16, UINT16, INT32, UINT32, FLOAT32, FLOAT64 (Endian supported)
