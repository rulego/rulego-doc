`x/mcWrite` component: <Badge text="v0.37.0+"/> Writes PLC devices via the Mitsubishi MC protocol (3E frame/binary, SLMP). Routes to `Success` or `Failure`.

> Requires: [rulego-components-iot](https://github.com/rulego/rulego-components-iot)

## Configuration

Connection settings are the same as [x/mcRead](/en/pages/x-mc-read/) (server/timeout/points). Write points are passed via `msg.Data`.

## Input/Output

- **Input**: `msg.Data` with point list `[{"name","addr","type","value"}]`
- **Output**: success routes to `Success`, failure routes to `Failure`

## Example

```json
{
  "id": "mc_write",
  "type": "x/mcWrite",
  "configuration": {
    "server": "192.168.1.30:6000"
  }
}
```

`msg.Data` with write points:

```json
[
  {"name": "setSpeed", "addr": "D200", "type": "UINT16", "value": "1500"},
  {"name": "start", "addr": "M10", "type": "BOOL", "value": "true"}
]
```
