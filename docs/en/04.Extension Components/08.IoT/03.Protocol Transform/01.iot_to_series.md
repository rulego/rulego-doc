`x/iotToSeries` component: <Badge text="v0.37.0+"/> Converts a map object or an array of map objects in `msg.Data` into `[]tsdb.SeriesPoint`, bridging acquisition aggregation results to [x/tsdbWrite](/en/pages/x-tsdb-write/).

> Requires: [rulego-components-iot](https://github.com/rulego/rulego-components-iot)

## Configuration

| Field | Type | Description | Default |
|------|------|------|--------|
| measurement | string | Measurement name, supports `${msg.xx}` / `${metadata.xx}` templates | `iot_data` |
| tags | object | Tag key/value mapping, tag values support templates | empty |
| fields | object | Field mapping in the form `{fieldName: sourceKey}`; empty means use the whole row | empty |
| timestampField | string | Row field holding Unix nanosecond timestamp; empty means current time | empty |

## Input Format

Supports either of the following:

- **Single object**

```json
{"temperature": 25.3, "humidity": 60, "ts": 1721900000000000000}
```

- **Object array**

```json
[
  {"device": "d1", "temperature": 25.3, "ts": 1721900000000000000},
  {"device": "d2", "temperature": 26.1, "ts": 1721900001000000000}
]
```

## Output Format

The output written back to `msg.Data` is `[]tsdb.SeriesPoint`:

```json
[
  {
    "measurement": "power_meter",
    "tags": {"deviceId": "d1"},
    "fields": {"temp": 25.3},
    "timestamp": 1721900000000000000
  }
]
```

## Mapping Rules

- `measurement`: shared measurement name for every row, rendered from templates
- `tags`: generated as string tags from configured templates
- `fields`: when empty, uses the whole row; otherwise only extracts declared source keys
- `timestampField`: falls back to current time if the field is missing or invalid

## Example

```json
{
  "id": "series",
  "type": "x/iotToSeries",
  "configuration": {
    "measurement": "power_meter",
    "tags": {
      "deviceId": "${metadata.deviceId}",
      "site": "${metadata.site}"
    },
    "fields": {
      "temp": "temperature",
      "hum": "humidity"
    },
    "timestampField": "ts"
  }
}
```

Input `msg.Data`:

```json
{"temperature": 25.3, "humidity": 60, "ts": 1721900000000000000}
```

## Typical Pipeline

```text
x/iotRead -> x/streamAggregator(pivot) -> x/iotToSeries -> x/tsdbWrite
```
