`x/finsRead` / `x/finsWrite`: Omron FINS protocol (UDP/TCP), reads/writes CS/CJ/CP/NSJ series PLC memory areas.

> Requires: [rulego-components-iot](https://github.com/rulego/rulego-components-iot)

## Configuration

| Field | Type | Description | Default |
|-------|------|-------------|---------|
| server | string | PLC host:port | `127.0.0.1:9600` |
| transport | string | udp or tcp | `udp` |
| timeout | int | Timeout (seconds) | `5` |
| points | array | Point table | — |

## Address Format

| Area | Word | Bit | Description |
|------|------|-----|-------------|
| DM | DM100 | DM100.3 | Data memory |
| CIO | CIO100 | CIO10.0 | CPU I/O |
| WR | WR200 | WR200.5 | Work area |
| HR | HR50 | HR50.2 | Holding relay |
| AR | AR10 | AR10.7 | Auxiliary relay |

## Data Types

BOOL, INT16, UINT16, INT32, UINT32, FLOAT32 (per-point Endian: ABCD/CDAB/BADC/DCBA)
