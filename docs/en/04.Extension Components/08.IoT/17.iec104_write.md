`x/iec104Write`: IEC 104 control commands — single/double command, scaled/float setpoint.

> Requires: [rulego-components-iot](https://github.com/rulego/rulego-components-iot)

## Command Types

| Type | Description | Value Format |
|------|-------------|--------------|
| C_SC_NA_1 | Single command | true/false or 1/0 |
| C_DC_NA_1 | Double command | 1(on)/2(off) |
| C_SE_NB_1 | Scaled setpoint | Integer (int16) |
| C_SE_NC_1 | Short float setpoint | Float |

## Input/Output

- **Input**: msg.Data with `[{"name","addr","type","value"}]`
- **Output**: Success/Failure routing
