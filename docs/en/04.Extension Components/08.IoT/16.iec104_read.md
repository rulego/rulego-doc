`x/iec104Read`: IEC 60870-5-104 master station, batch-reads substation telemetry via general interrogation.

> Requires: [rulego-components-iot](https://github.com/rulego/rulego-components-iot)

## Configuration

| Field | Type | Description | Default |
|-------|------|-------------|---------|
| server | string | Substation host:port (default port 2404) | `127.0.0.1:2404` |
| commonAddr | int | ASDU common address | `1` |
| timeout | int | Interrogation timeout (seconds) | `5` |
| points | array | Point table (addr=IOA) | — |

## Point Table Fields

| Field | Description | Example |
|-------|-------------|---------|
| name | Point name | Breaker1 |
| addr | Information Object Address (IOA) | 100, 16385 |
| type | Type ID (optional) | M_SP_NA_1, M_ME_NC_1 |

## Acquisition Model

Sends **General Interrogation (GI)**, substation responds with all data, values collected by IOA. Supports 9 ASDU types: single/double point, scaled/float measured values, integrated totals.

## Input/Output

- **Input** (optional): msg.Data with point list JSON (dynamic acquisition)
- **Output**: `[{"name","value","timestamp","error"}]`
